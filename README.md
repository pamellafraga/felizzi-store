# Dra. Maristela Arimilato

Site premium do consultório veterinário da Dra. Maristela Arimilato, no Jardim Botânico, em Porto Alegre.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## Stack

Next.js, TypeScript, Tailwind CSS, Framer Motion e Lucide React.

Imagens centralizadas em `src/data/images.ts`. Dados da clínica em `src/data/clinic.ts`.
